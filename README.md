# msg Machine Learning Catalogue

A catalogue of machine learning methods

## Preface

The [Machine Learning Catalogue](https://machinelearningcatalogue.com) is curated, designed, built and maintained by msg systems ag – msg Research.

It is intended for use when you want to obtain a list of methods that would be appropriate for a specific use case, or when you want to find out about a specific technique that is mentioned in an article, program or lecture. For each entry there is a textual description that gives an informal summary of what the method does; accessibility is deliberately prioritised over rigour.

The catalogue is organised in the following categories:

* **Algorithms** (53), normal machine learning procedures operating on data, e.g. [Decision Tree](https://machinelearningcatalogue.com/algorithm/decision-tree.html) or [Transformer](https://machinelearningcatalogue.com/algorithm/transformer.html).
* **Supporting techniques** (28), procedures that modulate the behaviour of one or more algorithms, e.g. [Cross-validation](https://machinelearningcatalogue.com/supporting-technique/Cross-validation.html).
* **Use cases** (36), typical problems and the methods suited to them, e.g. [Anomaly Detection](https://machinelearningcatalogue.com/use_case/anomaly-detection.html).
* **Data types** (16), **learning styles** (13) and **further concepts** (28) such as overfitting, drift or retrieval-augmented generation.

Algorithms and supporting techniques also carry structured information (aliases, subtypes, functional building blocks, learning styles, relevance, input and output data types, related methods). The [meta model](https://machinelearningcatalogue.com/about.html) shows how these building blocks relate to each other, and the [search](https://machinelearningcatalogue.com/search.html) supports `*`, `+` and `-` to refine a query.

A poster of the generic use cases is available as [PDF](docs/downloads/msg_Machine-Learning-Catalogue_Generic-Use-Cases_2.0.pdf).
